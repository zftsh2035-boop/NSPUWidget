# NSPUWidget v2.7 — «Очные», «Заочные», «Сессия» и плавная прокрутка

## Что изменилось

### 1. Вкладки как в официальном приложении НГПУ

- **В расписании преподавателя теперь три вкладки: «Очные», «Заочные», «Сессия».** Прежние «Неделя», «По датам», «Экзамены» переименованы под понятные пользователю категории официального приложения.
- **«Очные»** — расписание на неделю с понедельника по субботу, с переключением недель, числителя и знаменателя.
- **«Заочные»** — занятия по отдельным датам и месяцам, которые сайт НГПУ хранит в дополнительной таблице для заочного отделения и аспирантуры.
- **«Сессия»** — консультации, зачёты, экзамены и пересдачи, представленные в отдельном блоке официального расписания.
- Номер учебной недели и время проведения сохраняются. Предусмотрено отображение занятий по прошлым датам.

### 2. Вся информация сразу в карточке

- **Убрано раскрытие карточки по нажатию:** если дополнительное содержимое не даёт новой информации, лишнего действия быть не должно.
- **Диапазоны недель видны постоянно** в обычной плашке под предметом, временем и группой. Например, «(л.): 2,6–9 нед.» или «(п.з.): 6–10 нед.».
- **Исправлен разбор обоих вариантов записи сайта:** `(л.): 2,6-9 нед.` и `(л.: 2,6-9 нед.)`. Оба извлекаются в готовые данные карточки; добавлены отдельные тесты.
- **Остались компактные карточки в стиле Material 3** с названием дисциплины, временем, группой/аудиторией и короткой меткой типа `л.`, `п.з.`, `л.з.`, `зач.`, `экз.`.
- Группы и аудитории остаются обычным текстом, **без дополнительных кнопок-ссылок**.

### 3. Работа над плавностью прокрутки

- **Подготовка данных вынесена за пределы каждой карточки:** разделение занятий на дни, формирование подписей группы и аудитории, извлечение примечаний о неделях выполняются один раз для загруженного снимка расписания.
- **Убраны лишние состояния `expanded` и обработчики `clickable`** для каждой пары. Статические карточки теперь дешевле по составу и не запускают перестроение текста по касанию.
- **Тип занятия сокращается один раз при подготовке карточки**, а не на каждой её рекомпозиции.
- По-прежнему используется один `LazyColumn` без вложенных прокручиваемых списков и тяжёлого WebView.
- **Во время вертикального скролла основного расписания приостанавливается пульсация выделенной пары**, чтобы исключить конкурирующие кадровые перерисовки; после остановки прокрутки эффект возвращается.
- **Автопрокрутка к нужной паре больше не анимирует длинный переход списка**, а перемещает его сразу. Это устраняет принудительные анимации при переходе между днями.
- **Заголовок преподавателя допускает две строки**, чтобы имя и отчество не обрезались слишком рано.
- Сохранены введённые в 2.6 RAM/disk-кэш и фоновая перепроверка расписания. Уже полученная неделя не должна скачиваться заново при обычном скролле.
- **Важно:** это устраняет очевидные лишние вычисления. Реальное число пропущенных кадров и плавность на конкретном смартфоне необходимо проверить через Android Profiler/FrameTimeline после установки.

### 4. Тестирование и стабильность

- Добавлен регрессионный тест: примечание с диапазоном недель, кабинет и группа должны попадать в готовые данные карточки ещё до её создания.
- Сохранены предыдущие тесты числителя, знаменателя, датированных занятий и официальных ссылок.
- GitHub Actions собирает оптимизированные APK через R8 и публикует измеренный размер.
- Никаких изменений личного кабинета, оценок, «н-ок» и основной схемы расписания в этом выпуске нет.

## Сборка и подпись

GitHub Actions добавляет точный размер APK, тип подписи и SHA-256 после успешной сборки. Пока не задан постоянный ключ подписи через GitHub Secrets, используется оптимизированная debug-APK; Android может не позволить обновить предыдущую установку без переустановки и потери локальных данных.
