# NSPUWidget 2.12

- В окне обновления теперь видно, что изменилось: описание приходит из GitHub Releases. Большие списки прокручиваются, технические хеши и размеры APK остаются на странице выпуска.
- В разделе «О приложении» появилась кнопка «Что нового». Загруженное описание можно читать без интернета.
- В настройках виджета доступна диагностика: состояние кэша, системных ограничений, фоновых задач и последних обновлений можно скопировать одним отчётом. Тексты заметок и занятий в него не попадают.
- Сохранённое расписание отправляется в виджет до запуска фоновой синхронизации. Ошибки планировщика больше не прерывают этот шаг; при ошибке отрисовки показывается предложение открыть приложение.
- Начальный шаблон больше не сообщает об отсутствии занятий до загрузки данных. Пустой кэш и ошибка сети отображаются отдельно от дня без пар.
- Новый значок приложения: календарь с выделенной парой и часами. Поддерживаются тематические значки Android.

Причина сбоя на Blackview BV4900 пока не подтверждена: для точного вывода нужен отчёт с этого телефона. Дополнительные разрешения для виджета не запрашиваются.

Обновление поверх v2.11 сохраняет данные и использует тот же постоянный ключ. При переходе с более старой версии с другой подписью сначала скопируй заметки: удаление приложения стирает локальные данные.
