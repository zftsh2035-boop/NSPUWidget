# NSPUWidget v2.4 — исправлена навигация и добавлены расписания преподавателей/аудиторий

## Что изменилось

### 1. Исправлено переключение на предыдущий день

- **Исправлена ситуация, когда приложение после последней пары автоматически открывало завтрашний день, а нажатие «Назад» возвращало тот же завтрашний день.** Причина: значение смещения `offset = 0` одновременно означало «сегодня» и «автоматически выбрать ближайший учебный день».
- **Добавлена отдельная дата, выбранная пользователем, `selected_date`.** Она хранится как конкретный день календаря (`YYYY-MM-DD`) и не конфликтует с автоматическим выбором ближайшей пары.
- **Автоматический режим сохраняется при первом открытии.** Когда студент ещё не выбирал день вручную, приложение по-прежнему может показывать день ближайшего занятия, в том числе следующее утро после последней пары.
- **Любое ручное действие фиксирует выбранную дату.** Это относится к свайпам влево/вправо, кнопкам календарных дней, стрелкам виджета и кнопке «Сегодня». Выбор сегодняшнего дня не превращается обратно в автоматический режим и не перескакивает на завтра.
- **Сохраняется точная дата при наступлении полуночи.** Если пользователь вручную просматривает вчерашнее расписание, оно не смещается автоматически, пока не выберет другую дату.
- **Учтены старые установки:** предыдущие ненулевые смещения дней читаются как сохранённый выбор до первого нового перехода. При смене группы ручной выбор очищается.
- **Добавлены регрессионные тесты** на сценарий «после последней пары следующий день → назад → сегодня», на повторный переход назад, вперёд и на переход через полночь.

### 2. Открытие расписания преподавателя

- **Фамилии преподавателей стали нажимаемыми там, где официальный сайт НГПУ содержит ссылку.** Нажатие открывает оригинальное расписание преподавателя в браузере Android. Рядом с фамилией отображается небольшая стрелка ↗.
- **Никакого угадывания ID по фамилии.** Во время загрузки расписания приложение читает реальные ссылки `teacher_shedule.php?id=...` прямо из HTML страницы выбранной группы. Это защищает от путаницы между однофамильцами и неправильными адресами.
- **Фильтруются ссылки посторонних сайтов.** Переход доступен только на официальные страницы `https://schedule.nspu.ru`, найденные в документе.
- **Если ссылка не указана на сайте**, преподаватель просто остаётся обычным текстом — без пустых кнопок или ошибочных переходов.

### 3. Открытие расписания аудитории

- **Номер аудитории теперь тоже становится ссылкой**, если официальный сайт предоставляет соответствующую страницу `room_shedule.php?id=...`.
- **Поддерживаются не только цифровые номера,** но и названия помещений (например, аудитории с буквой или спортивный зал), если они представлены корректной ссылкой на сайте.
- **Реальные ID сохраняются вместе с кэшем выбранной группы,** поэтому уже загруженные ссылки доступны без повторной загрузки при каждом нажатии.
- **Для старых установок загрузка ссылок инициируется отдельно при первом запуске 2.4**, даже когда само расписание уже сохранено локально. При отсутствии сети расписание продолжает открываться из кэша; новые ссылки появятся после успешной синхронизации.
- **Смена группы очищает ссылки предыдущей группы**, предотвращая переход к несоответствующей аудитории/преподавателю.
- **Никакого тяжёлого встроенного браузера:** используются стандартные ссылки `ACTION_VIEW` на официальном сайте. Интерфейс приложения сохраняет Kotlin/Compose и существующий размер APK.

### 4. Основа для развития студенческого приложения

- **Добавлен документ `docs/ARCHITECTURE.md`** с планом разделения приложения на публичное расписание, преподавателей/аудитории, объявления, оценки, пропуски («н-ки»), личный кабинет, настройки и виджеты.
- **Предложена модульная архитектура без поспешного переписывания:** сначала пакеты и репозитории с интерфейсами внутри текущего Android-модуля, затем Room, ViewModel и по необходимости отдельные Gradle-модули.
- **Публичное расписание должно остаться доступным без авторизации.** Оценки, посещаемость и личные данные будут отдельными функциями — только после подтверждения официального способа подключения НГПУ.
- **Безопасность будущего кабинета:** авторизация через официальный сервис, без хранения паролей в открытых настройках или репозитории; токены под защитой Android Keystore; локальные приватные сведения удаляются при выходе; никаких чувствительных данных в виджете по умолчанию.
- **Личному кабинету в этом выпуске ничего не подключено.** Перед реализацией нужно подтвердить официальный API/SSO и правила работы с персональными данными. Это предотвращает появление ненадёжной имитации кабинета.

### 5. Что осталось неизменным

- Материал 3, независимые темы приложения/виджета, AMOLED и Neon.
- Работа с расписанием офлайн из кэша, подгруппы, уведомления и история изменений.
- Свайпы между днями и подсветка текущей пары.
- Виджет со списком пар, кнопкой прочтения объявления и компактный виджет.
- R8, удаление неиспользуемых ресурсов, трёхчасовая синхронизация WorkManager.

### 6. Тестирование и установка

- **GitHub Actions:** регрессионные unit-тесты, создание R8-оптимизированных debug/release-вариантов, проверка целостности APK. Фактический статус см. в разделе Actions.
- **Тесты HTML-ссылок:** проверка ссылок на преподавателя и аудитории, отсутствия несуществующей аудитории и отклонения сторонних URL.
- **Автоматические тесты — не полная гарантия поведения на любом смартфоне.** После установки проверь свайп назад после последней пары и открытие преподавателя/аудитории при наличии интернета.
- **Debug-подпись:** постоянный ключ релиза ещё не настроен. При несовпадении подписи Android может потребовать переустановить приложение, что удалит локальные настройки.
