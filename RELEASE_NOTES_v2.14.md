# NSPUWidget 2.14

- Исправлен порядок занятий в расписаниях преподавателей и аудиторий: `8:30` теперь предшествует `10:10` и вечерним парам независимо от ведущего нуля.
- Занятия с указанной датой и пустой ячейкой времени больше не пропадают. В частности, отображается заочное расписание аудитории 218 из группы 4.021.1.26.
- Если источник не указал время, карточка показывает «Время не указано». Повторяющиеся записи без времени сохраняются отдельно.
- При первом открытии страницы с пустым очным разделом и опубликованными заочными занятиями автоматически выбирается заполненный раздел. Ручной выбор вкладки сохраняется.
- Старый кэш расписаний преподавателей и аудиторий обновляется для исправленного разбора.
- Несколько кодов групп в одной ссылке через точку с запятой больше не создают ложные пары и не теряют уточнение времени.
