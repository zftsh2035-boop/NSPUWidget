# NSPUWidget v2.6 — быстрый и компактный просмотр расписания преподавателей

## Что изменилось

### 1. Интерфейс ближе к приложению «НГПУ Расписание»

- **Упростили экран расписания преподавателя и аудитории.** Вместо крупной цветной шапки и множества отдельных кнопок — сдержанная верхняя строка с именем, переключение недель и один прокручиваемый список занятий.
- **Вся неделя видна на одном экране.** Последовательно идут понедельник, вторник, среда, четверг, пятница, суббота; под каждым днём — его пары. Не нужно по очереди выбирать шесть дней, чтобы понять занятость преподавателя.
- **Карточки стали заметно компактнее:** предмет, время, подпись группы/кабинета/преподавателя и обозначение `л.`, `п.з.`, `л.з.`, `зач.`, `экз.`. Цвета соответствуют Material 3 и выбранной теме.
- **Убраны переходы по ссылкам на группы и аудитории внутри расписания.** Их названия/номера выводятся только как обычный текст; нет горизонтальной карусели `AssistChip` и лишних вложенных `LazyRow` для каждой пары.
- **Подробности пары раскрываются обычным нажатием на карточку**, если требуется посмотреть полную формулировку с сайта и недели проведения.
- **Сохранены отдельные вкладки «По датам» и «Экзамены»**, возможность показать прошедшие занятия, номер недели и её числитель/знаменатель. Данные продолжают поступать с официального сайта.

### 2. Кэш для мгновенного повторного открытия

- **Новый двухуровневый кэш:** до 16 недавно открытых недель в оперативной памяти и до 28 JSON-снимков в собственном дисковом кэше Android. После перезапуска приложения уже просмотренный преподаватель открывается из сохранённых данных без повторного скачивания HTML.
- **Первые 20 минут данные считаются свежими.** Позже приложение может сразу показать доступный кэш и тихо перепроверить расписание в фоне. Снимки старше суток не используются, чтобы не показывать слишком старую информацию как актуальную.
- **Переключение уже просмотренной недели больше не очищает весь экран ради загрузки.** Если подходящий снимок сохранён, расписание появляется сразу; тонкая полоса прогресса показывает фоновое обновление.
- **Параллельные запросы на одну страницу объединяются.** Предварительная загрузка и открытие преподавателя не должны создавать два одинаковых HTTP-запроса.
- **Перед входом в расписание** приложение предварительно загружает одного преподавателя из текущего дня, когда пользователь уже просматривает группу. Предзагрузка запускается с небольшой задержкой на фоне, а не в UI-потоке; приложение не скачивает списки всех преподавателей университета.

### 3. Меньше ненужной работы UI

- **Убраны вложенные горизонтальные списки ссылок** из каждой карточки. Уроки отображаются простыми поверхностями с ограниченным количеством текстовых элементов.
- **Сохранён один вертикальный `LazyColumn`,** в котором парные карточки создаются по мере прокрутки. Не используется `WebView`, JavaScript, Chromium или дорогостоящая загрузка веб-шрифтов.
- **Состояние домашнего расписания теперь сохраняется при открытии экрана преподавателя** через `SaveableStateProvider`. Возврат назад не обязан заново сбрасывать прокрутку и выбранные элементы.
- **Убрано дорогое вычисление внутренних размеров `IntrinsicSize.Min` у каждой карточки основной группы.** Цветная вертикальная полоса теперь рисуется в одном проходе через `drawBehind`, без повторного измерения содержимого; элементам списка добавлены стабильные ключи, чтобы Compose мог переиспользовать их при изменениях расписания.
- **Ручное обновление отделено от переключения недель**: нажатие ⟳ действительно обновляет выбранный период, но не заставляет принудительно перезагружать все последующие недели.

### 4. Диагностика и честные ограничения

- **Добавлены замеры времени сетевого ответа сайта** (TTFB и полное время ответа) в GitHub Actions `dev`, а также журнал длительности получения и разбора страницы в Android Logcat. Это помогает отличить медленный университетский сервер от лагов интерфейса.
- **Первое открытие незнакомого преподавателя по-прежнему может зависеть от скорости сайта НГПУ.** Дисковый кэш и предзагрузка ускоряют повторные/подготовленные страницы, но не гарантируют мгновенный ответ при холодной загрузке из интернета.
- **Сохранены все темы**, в том числе отдельные настройки темы виджетов и приложения, Neon и AMOLED; расписание группы, замены и объявления не перерабатывались.
- **Новая release-сборка проходит R8, unit-тесты и проверку APK** в GitHub Actions; эмуляторная проверка не заменяет профилирование на настоящем смартфоне.

## Размер и подпись APK

GitHub Actions дописывает фактический размер APK, SHA-256 и тип подписи после сборки.

## Репозиторий

`stable` — проверенные релизы; `dev` — экспериментальные изменения; `main` — зеркало стабильной версии.
