# НГПУ — виджет расписания Android

Нативный Android-виджет для группы **3.008.2.26** (НГПУ, ИФМИТО). Показывает пары и объявления с официального сайта, хранит последнюю успешную версию офлайн и проверяет обновления примерно каждые 3 часа.

**Источник расписания:** https://schedule.nspu.ru/group_shedule.php?id=3328

Проект включает Android-приложение на Kotlin, WorkManager, AppWidget и GitHub Actions для сборки отладочного APK. В разделе **Actions → Build Android APK** доступна сборка; после успеха APK скачивается из **Artifacts**.

Объявления из верхнего блока отображаются отдельно; новые подсвечиваются, для Android 13+ уведомления требуют разрешения. Первая загрузка создаёт базовую версию без рассылки устаревших сообщений.

Трёхчасовая проверка — приблизительная: Android может откладывать фоновую работу. Приложение не является официальным продуктом НГПУ.
