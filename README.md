# NSPUWidget

Неофициальное Android-приложение и виджет расписания НГПУ.

## Версия 2.11 — заметки и планирование

- Заметки к парам и отдельные записи на день, в том числе на день без занятий. Для событий доступны название и компактные плитки.
- Период показа настраивается в редакторе; полный список заметок остаётся доступен всегда.
- До 32 отдельных напоминаний с датой и временем. Редактор показывает, разрешены ли уведомления и точные сигналы Android.
- Сохранённая заметка открывается целиком в окне чтения с прокруткой и копированием. Лимит текста — 20 000 символов.
- Лента дат прокручивается в обе стороны; заголовок даты открывает календарь.
- Группа и звёздочка закреплены в верхней панели, дублирующая плитка убрана.
- При добавлении виджета из приложения используются безопасные начальные размеры, адаптивные раскладки Android 12+ и обновление после подтверждения установки.
- [Подробные изменения v2.11](RELEASE_NOTES_v2.11.md) и [состояние проверок](docs/VERIFICATION_v2.11.md).

## Версия 2.10 — личные заметки

- Приветственное окно предлагает поставить виджет кнопкой или по короткой инструкции. Позже установка доступна в настройках.
- Значок заметки рядом со временем пары открывает запись к этой группе и дате, например «взять бинты».
- Текст виден в приложении и виджете; в маленьком виджете он заменяет строку преподавателя.
- Нажми на заметку в виджете, чтобы изменить или удалить её в приложении. Общий список — кнопка **Мои заметки** в верхней панели.
- Работают без интернета, хранятся отдельно от загружаемого расписания. Синхронизации между устройствами нет.
- [Подробные изменения v2.10](RELEASE_NOTES_v2.10.md).

## Версия 2.9 — избранные группы

- Кнопка **☆** в приложении и любом размере виджета открывает избранное. В виджете список появляется на месте расписания, без открытия приложения.
- **Добавить группу** → институт → группа. По умолчанию показывается код группы; **⋮ → Переименовать** задаёт своё имя. Пустое имя возвращает исходное название.
- При выборе группы приложение переходит к её текущей или ближайшей паре, включая ближайший учебный день; явный выбор работает и с выключенной общей автопрокруткой.
- Несколько виджетов независимо хранят группу и выбранный день; просмотр в приложении их не переключает. Сохранённые расписания доступны офлайн.
- У каждой группы свои кэш, языковая подгруппа, объявления и история изменений. Старые данные v2.8 переносятся при первом запуске.
- Один планировщик обновляет избранные группы раз в три часа; уведомления отправляются для основной группы. Смена названия и выбор группы не требуют сетевой загрузки, если есть кэш.
- [Подробные изменения v2.9](RELEASE_NOTES_v2.9.md).

## Оптимизация просмотра преподавателей (v2.6)

- Вместо громоздкого интерфейса — компактная нативная недельная лента Material 3 в духе официального Android-приложения НГПУ. Все дни показаны последовательно.
- Из карточек просмотра преподавателя убраны **кнопки-ссылки на группы и аудитории**; группы и аудитории теперь просто поясняют, где и с кем проходит занятие.
- Введён **постоянный дисковый кэш** страниц (наряду с ограниченным кэшем ОЗУ), фоновая перепроверка устаревших записей и предварительная загрузка ближайшего преподавателя.
- Результат при первом посещении зависит от скорости сайта: повторный просмотр будет быстрее благодаря кэшу, а холодный сетевой запрос не гарантированно мгновенный.
- [Подробные изменения версии 2.6](RELEASE_NOTES_v2.6.md).

## Встроенные расписания — версия 2.5

При нажатии на преподавателя или аудиторию теперь открывается **нативный экран Material 3** (не WebView): дни и недели, числитель/знаменатель, занятия по датам и экзамены. Ссылки на преподавателей, аудитории и группы также открываются внутри приложения. Используется официальный HTML НГПУ, лёгкий парсер Jsoup и краткоживущий кэш, поэтому список работает без тяжёлого браузерного движка.

Подробный маркированный [список изменений 2.5](RELEASE_NOTES_v2.5.md). Остальные запланированные возможности студенческого кабинета пока отложены.

## Темы приложения и виджетов (v2.2)

Темы приложения и виджетов **настраиваются отдельно** с версии 2.3. В настройках доступны `Системная` (по дневной/ночной теме Android), `Светлая`, `Тёмная`, `AMOLED` (чёрный фон с сохранённым системным акцентом) и `Neon` (чёрный фон, кислотный зелёный/циан/розовый). Выбор темы приложения меняет только его интерфейс; тема виджетов управляется отдельным переключателем и при смене обновляет все установленные виджеты. По умолчанию виджет следует системной теме Android.

Подробные изменения: [v2.3](RELEASE_NOTES_v2.3.md), [v2.2](RELEASE_NOTES_v2.2.md).

## Настройки (версия 2.0)

В нижней панели есть раздел **Настройки**:

- **Канал обновлений — Stable / Dev.** Stable ищет новые версии в [GitHub Releases](https://github.com/zftsh2035-boop/NSPUWidget/releases). Dev ищет последние **успешные** сборки именно ветки `dev` в [GitHub Actions](https://github.com/zftsh2035-boop/NSPUWidget/actions/workflows/build-apk.yml?query=branch%3Adev). Из dev раздела можно открыть запуск и скачать APK из Artifacts (GitHub может требовать вход). Dev-сборки **не** считаются стабильными релизами и не публикуются в Releases.
- Новые версии проверяются максимум раз в 6 часов при запуске приложения; кнопка **Проверить обновления** делает проверку по запросу. Если пользователь закрывает окно «Доступно обновление» / выбирает «Не сейчас», для **этого** номера версии или конкретного dev-коммита его больше не покажут. Автоматического скачивания или установки нет. Плитка GitHub не мешает просмотру расписания и находится **только в настройках**.
- **Темы приложения и виджета** — два независимых набора: Системная, Светлая, Тёмная, AMOLED и Neon. Системная тема следует Android; Dynamic Color используется на Android 12+. AMOLED сохраняет системный акцент, но делает фон полностью чёрным. На более старых устройствах используется стандартная цветовая палитра.
- **Расписание** — можно выключить анимацию главной пары или автопрокрутку к ней. Параметры сохраняются на устройстве.
- **О приложении** — информация о версии, независимом статусе проекта и прямая ссылка на [GitHub](https://github.com/zftsh2035-boop/NSPUWidget).

## Ветки

- `dev` — рабочая ветка; push запускает тесты и сборку APK в GitHub Actions, без публикации в Releases.
- `stable` — проверенная версия; после успешной сборки публикуется новый релиз и APK.
- `main` — зеркало последней проверенной версии.

## Оптимизация (версия 2.1)

- **R8 + shrinking ресурсов:** `app/build.gradle.kts` включает `isMinifyEnabled` и `isShrinkResources` в debug и release вариантах. Результат измеряется CI; размер v2.0 составлял 9 437 386 байт.
- **Меньше перерисовок Compose:** не запускаем глобальную рекомпозицию каждые 15 секунд. `SharedPreferences.OnSharedPreferenceChangeListener` замечает изменения расписания; обратный отсчёт обновляется локально один раз в минуту, пока экран открыт.
- **Кэш моделей в оперативной памяти:** уже распарсенные уроки, объявления и история изменений переиспользуются, пока их сохранённые JSON-строки не поменяются. Выбор языковых подгрупп вычисляется из того же набора уроков.
- **Трёхчасовая синхронизация через WorkManager:** без постоянно работающих служб; компактный виджет показывает ближайшую пару через `RemoteViews`, без Compose-анимации.
- **Адаптивный компактный виджет:** отдельные обычная и узкая/низкая разметки, метка типа занятия, предмет, время, преподаватель и аудитория; текст не наезжает на соседние поля.
- **Отключён периодический 30-минутный вызов AppWidgetProvider:** виджет обновляют WorkManager и запланированный сигнал изменения текущей пары; Android может задерживать фоновое обновление ради энергосбережения.

### Замеры производительности

Workflow [Android performance comparison](https://github.com/zftsh2035-boop/NSPUWidget/actions/workflows/performance.yml) сравнивает v2.9 и текущую версию на одинаковых сохранённых расписаниях, проверяет переходы преподавателя/аудитории и сохраняет кадры, память и скриншоты. Отдельный тестовый launcher-host проверяет четыре избранные группы, два настоящих виджета, независимые даты, переименование и переход к ближайшей паре. Проверяются также заметки, миграция старой базы, полный текст, напоминания и календарь. Host и fixture APK не входят в распространяемое приложение.

Проверка выполняется **только на одноразовом эмуляторе**: скрипты специально переустанавливают приложение и подставляют тестовые данные. Это не измерение автономности и не гарантия скорости на любом смартфоне. Инструкции запуска находятся в workflow; результаты — в артефакте `Android29-performance-comparison`.

### Постоянная подпись релиза

Для стабильного выпуска необходим GitHub Actions Secret `NSPU_SIGNING_BUNDLE`: приватный JSON с полями `keystore_base64`, `store_password`, `key_alias`, `key_password`. Поддерживается и прежний формат из четырёх секретов: `NSPU_KEYSTORE_B64`, `NSPU_KEYSTORE_PASSWORD`, `NSPU_KEY_ALIAS`, `NSPU_KEY_PASSWORD`. Сам keystore и пароли не публикуются. Без ключа stable-сборка останавливается до выпуска; dev можно собрать с временной подписью для проверки. Когда постоянный ключ доступен, распространяемые debug и release APK используют одну подпись.

Создать ключ можно локально: `keytool -genkeypair -v -keystore nspu-release.jks -alias nspu -keyalg RSA -keysize 3072 -validity 10000`. Пароли вводи локально, а keystore храни в резервной копии вне GitHub. GitHub Secrets добавляются через репозиторий → Settings → Secrets and variables → Actions. Новый постоянный ключ **не совпадёт** с временными debug-подписями старых APK. Перед удалением старого приложения обязательно скопируй заметки: удаление стирает локальные данные.
