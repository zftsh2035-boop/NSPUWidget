# НГПУ · нативный виджет Android · группа 3.008.2.26

**Версия 1.1, исходный код для сборки APK.** Данные загружаются исключительно с официальной страницы [НГПУ](https://schedule.nspu.ru/group_shedule.php?id=3328).

## Что умеет

- Нативный виджет Android (AppWidget) прямо на домашнем экране, рекомендованный размер **4×5** ячеек (можно менять размер).
- Занятия текущего дня, переход на следующий/предыдущий день, возврат к сегодняшнему дню.
- Фильтр подгруппы по иностранному языку **А1–А10** и «Немецкий» в основном приложении.
- **Объявления с верхней части сайта** показываются *над парами*. По нажатию на объявление открывается основное приложение с полным текстом.
- Если опубликовано новое сообщение, его выделение сохраняется до отметки «Прочитано». Объявления старше 7 дней от первой найденной в их тексте даты помечены «Архив», но не скрываются, пока присутствуют на сайте.
- Android-уведомления при появлении новых сообщений (для Android 13+ нужно нажать «Разрешить уведомления» в приложении). При первом запуске существующие объявления считаются базовой версией, чтобы не прислать старые «срочные» уведомления.
- **WorkManager** проверяет расписание каждые ~3 часа при доступной сети. Android может отложить проверку, например в Doze. Точного SLA в 3 часа нет.
- Кнопка «⟳» запускает проверку по запросу. При сбое связи сохраняется последняя успешно загруженная версия; ошибка видна в приложении.
- Обнаружение изменённых занятий по времени/названию/подгруппе и подсветка новых/изменённых записей до отметки «Прочитано».
- Локальный кэш в SharedPreferences; никакой собственной учётной записи или сервера не требуется.
- Временная зона для определения дня и недели: **Asia/Novosibirsk**, неделя 1 начинается 31 августа 2026 г.

## Как получить APK: Android Studio

1. Распакуй архив, чтобы папка `NSPUWidget` лежала целиком вместе с `app/`, `settings.gradle.kts`, `build.gradle.kts`.
2. Открой `NSPUWidget` в Android Studio. Убедись, что установлены Android SDK Platform 35, Gradle **8.9**, JDK **17** и есть доступ к Google Maven / Maven Central. В этой версии исходников нет бинарного `gradle-wrapper.jar`; если Android Studio требует Gradle Wrapper, создай его с установленным Gradle (`gradle wrapper --gradle-version 8.9`) или выбери локально установленный Gradle 8.9.
3. Дождись Gradle Sync и выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Результат: `app/build/outputs/apk/debug/app-debug.apk`.
5. Установи APK, запусти «Расписание НГПУ» хотя бы один раз, выбери подгруппу, разреши уведомления по желанию и нажми «⟳ Обновить».
6. На домашнем экране Android удерживай свободное место → **Виджеты → Расписание НГПУ** → добавь на экран и при необходимости растяни до 4×5 ячеек.

## Как получить APK: GitHub Actions (без Android Studio)

В репозитории есть `.github/workflows/build-apk.yml`. Загрузи *содержимое* папки `NSPUWidget` в корень своего GitHub-репозитория, открой **Actions → Build Android APK → Run workflow** и скачай `NSPUWidget-Android-debug-APK` в разделе **Artifacts** после успешной сборки. Это отладочный APK: его можно поставить себе на телефон, но он не подписан релизным ключом и не предназначен для публикации в Google Play.

## Быстрая проверка парсера без Android

```bash
kotlinc app/src/main/java/ru/nspu/schedule/SiteParser.kt tools/ParserSmokeTest.kt -include-runtime -d /tmp/parser-test.jar
java -jar /tmp/parser-test.jar
```

Тест проверяет распознавание объявлений, устаревшую дату 05.10.2026, три подгруппы, недельные диапазоны и дату субботнего зачёта. **Это тест репрезентативного текстового фрагмента страницы, а не end-to-end тест действующего сайта**.

## Устройство проекта

- `SiteParser.kt` — разбор расписания, объявлений, учебных недель и подгрупп.
- `Store.kt` — HTTPS-загрузка, валидация ответа, сравнение с кэшем, хранение и отметка о прочтении.
- `Sync.kt` — периодическая работа WorkManager и ручная синхронизация.
- `AnnouncementNotifier.kt` — системные уведомления о новых объявлениях.
- `ScheduleWidget.kt`, `res/layout/widget.xml` — нативный AppWidget и его действия.
- `MainActivity.kt` — полный текст объявлений, список пар, фильтр подгрупп, ручное обновление.

## Реальные ограничения и предосторожности

- Сайт НГПУ может менять HTML; парсер будет требовать правок при существенном изменении структуры. Неуспешная загрузка **не заменяет** кэш пустыми данными.
- При одной паре на сайте могут быть несколько записей по разным подгруппам; парсер разделяет их по `;`, но если сайт изменит правила разделения, нужна адаптация.
- Текстовые объявления не всегда содержат формализованный срок действия. Программа **не переносит автоматически занятия** из текста объявления в основную сетку: показывает исходный текст и дату без домыслов. «Архив» означает возраст указанной даты, а не официальное снятие объявления.
- Новые уведомления — только при успешной проверке и если пользователь дал разрешение. Системные ограничения энергосбережения могут откладывать синхронизацию.
- В виджете показываются **первые четыре подходящих занятия** на выбранный день; полный день и все объявления доступны при открытии приложения. Виджет не имеет самостоятельной прокрутки списка.
- Проверка на парсерном smoke-тесте прошла; **полная Gradle-сборка APK и запуск на Android-телефоне в текущей среде не выполнялись**, поскольку Android SDK / Gradle здесь не установлены.
