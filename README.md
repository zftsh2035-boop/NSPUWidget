# NSPUWidget

Нативный Android-виджет расписания НГПУ: выбор любой группы через каталог институтов, офлайн-кэш, периодическая проверка сайта и уведомления о новых объявлениях.

## Версия 1.3

- Материал-дизайн: приложение переписано на Jetpack Compose + Material 3 (Material You с динамическими цветами на поддерживаемых устройствах).
- Прокрутка виджета: все занятия в прокручиваемом списке (без лимита на четыре пары).
- Формат НГПУ: обозначения типов **Л., П.З., Л.З., З., Э.**
- Наглядность: отдельное время, предмет, преподаватель, аудитория и цветная полоска по типу занятий.
- Объявления: только текущие на сайте и новые. Сообщение не объявляется устаревшим из-за даты в тексте.
- Иконка: адаптивный значок с академической шапочкой и календарём, поддержка тематического оформления.
- Фоновое обновление примерно каждые 3 часа (WorkManager ограничивает точное время).

## Скачать приложение

См. [GitHub Releases](https://github.com/zftsh2035-boop/NSPUWidget/releases/latest). Файл NSPUWidget-v1.3-debug.apk — отладочная сборка для установки вручную.

## Разработка

Открыть проект в Android Studio либо использовать автоматическую сборку GitHub Actions. SDK 35, Java 17, Gradle 8.9, Kotlin 2.0.21.

> Независимый студенческий проект, неофициальное приложение университета. Данные сайта НГПУ могут измениться: перед важными зачётами и экзаменами сверяй информацию с официальным расписанием.
