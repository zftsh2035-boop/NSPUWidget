# NSPUWidget

Нативное приложение и виджет расписания НГПУ для Android: выбор группы, актуальные объявления, кэш расписания, цветные пары, автоматическое выделение текущей пары, история изменений и обновление через GitHub.

## Загрузка

**Проверенный выпуск:** [GitHub Releases](https://github.com/zftsh2035-boop/NSPUWidget/releases/latest).

**Отладочные APK:** сборки debug подписаны отладочным ключом. При разных ключах подписи Android может не позволить установить новую APK поверх старой.

## Обновления (начиная с версии 1.8)

Приложение при открытии проверяет последний **публичный стабильный** выпуск через [GitHub Releases API](https://api.github.com/repos/zftsh2035-boop/NSPUWidget/releases/latest), не чаще одного запроса за 6 часов. Если найден выпуск с версией выше установленной, **один раз для этой версии** появляется окно «Доступно обновление», кнопки «Скачать» и «Не сейчас».

Выбор и даже закрытие окна не вызывают повторный диалог для той же версии; это записывается только в локальные настройки Android. Постоянная ненавязчивая плитка «GitHub · Релизы» остаётся для ручного открытия. Ни установка, ни скачивание не происходят автоматически.

## Ветки и выпуск APK

- `stable` — проверенная версия. Только push сюда запускает публикацию APK в GitHub Releases.
- `dev` — разработка. Тесты и сборка APK выполняются в GitHub Actions, но публикации в Releases нет.
- `main` — сохранённая основная ветка для совместимости, зеркалируется с `stable` после выпуска.

Каждый push в main/stable/dev запускает тесты и сборку APK в GitHub Actions. Для выпуска: сначала исправить ошибки и проверить `dev`, потом выполнить fast-forward `stable` и `main` на проверенный коммит.

## Сборка

Android SDK 35, Java 17, Gradle 8.9, Kotlin 2.0.21, Jetpack Compose Material 3.
