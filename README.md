# NSPUWidget

Неофициальное Android-приложение и виджет расписания НГПУ.

## Загрузка

[Последний проверенный релиз (stable)](https://github.com/zftsh2035-boop/NSPUWidget/releases/latest)

## Настройки (версия 2.0)

В нижней панели есть раздел **Настройки**:

- **Канал обновлений — Stable / Dev.** Stable ищет новые версии в [GitHub Releases](https://github.com/zftsh2035-boop/NSPUWidget/releases). Dev ищет последние **успешные** сборки именно ветки `dev` в [GitHub Actions](https://github.com/zftsh2035-boop/NSPUWidget/actions/workflows/build-apk.yml?query=branch%3Adev). Из dev раздела можно открыть запуск и скачать APK из Artifacts (GitHub может требовать вход). Dev-сборки **не** считаются стабильными релизами и не публикуются в Releases.
- Новые версии проверяются максимум раз в 6 часов при запуске приложения; кнопка **Проверить обновления** делает проверку по запросу. Если пользователь закрывает окно «Доступно обновление» / выбирает «Не сейчас», для **этого** номера версии или конкретного dev-коммита его больше не покажут. Автоматического скачивания или установки нет. Плитка GitHub не мешает просмотру расписания и находится **только в настройках**.
- **Тема** — Системная, Светлая, Тёмная и AMOLED. Системная тема следует Android; Dynamic Color используется на Android 12+. AMOLED сохраняет системный акцент, но делает фон полностью чёрным. На более старых устройствах используется стандартная цветовая палитра.
- **Расписание** — можно выключить анимацию главной пары или автопрокрутку к ней. Параметры сохраняются на устройстве.
- **О приложении** — информация о версии, независимом статусе проекта и прямая ссылка на [GitHub](https://github.com/zftsh2035-boop/NSPUWidget).

## Ветки

- `dev` — рабочая ветка; push запускает тесты и сборку APK в GitHub Actions, без публикации в Releases.
- `stable` — проверенная версия; после успешной сборки публикуется новый релиз и APK.
- `main` — зеркало последней проверенной версии.

## Оптимизация (версия 2.1)

- **R8 + shrinking ресурсов:** `app/build.gradle.kts` включает `isMinifyEnabled` и `isShrinkResources` в debug и release вариантах. Результат измеряется CI; размер v2.0 составлял 9 437 386 байт.
- **Меньше перерисовок Compose:** не запускаем глобальную рекомпозицию каждые 15 секунд. `SharedPreferences.OnSharedPreferenceChangeListener` замечает изменения расписания; обратный отсчёт обновляется локально один раз в минуту, пока экран открыт.
- **Кэш моделей в оперативной памяти:** уже распарсенные уроки, объявления и история изменений переиспользуются, пока их сохранённые JSON-строки не поменяются. Выбор языковых подгрупп вычисляется из того же набора уроков.
- **Трёхчасовая синхронизация через WorkManager:** без постоянно работающих служб; компактный виджет показывает ближайшую пару через `RemoteViews`, без Compose-анимации.
- **Адаптивный компактный виджет:** отдельные обычная и узкая/низкая разметки, метка типа занятия, предмет, время, преподаватель и аудитория; текст не наезжает на соседние поля.
- **Отключён периодический 30-минутный вызов AppWidgetProvider:** виджет обновляют WorkManager и запланированный сигнал изменения текущей пары; Android может задерживать фоновое обновление ради энергосбережения.

### Замеры производительности

Workflow [Android performance smoke](https://github.com/zftsh2035-boop/NSPUWidget/actions/workflows/performance.yml) запускает Android-эмулятор и собирает пять измерений запуска, память `dumpsys meminfo`, кадры `dumpsys gfxinfo`, CPU snapshot и снимок экрана. Результаты хранятся в Artifacts. Это **не** измерение автономности и не гарантия скорости на любом смартфоне.

Для собственного устройства с ADB: `bash tools/profile_android.sh app/build/outputs/apk/debug/app-debug.apk performance-results`. Скрипт устанавливает APK и может заменить уже установленное приложение.

### Постоянная подпись релиза

Release APK подписывается постоянным приватным ключом **только** если владелец настроил GitHub Actions Secrets: `NSPU_KEYSTORE_B64`, `NSPU_KEYSTORE_PASSWORD`, `NSPU_KEY_ALIAS`, `NSPU_KEY_PASSWORD`. Сам keystore и пароли не публикуются. При отсутствии всех четырёх секретов GitHub Releases продолжает предоставлять оптимизированную устанавливаемую **debug-APK**; это осознанно не считается полной release-подписью.

Создать ключ можно локально: `keytool -genkeypair -v -keystore nspu-release.jks -alias nspu -keyalg RSA -keysize 3072 -validity 10000`. Пароли вводи локально, а keystore храни в резервной копии вне GitHub. GitHub Secrets добавляются через репозиторий → Settings → Secrets and variables → Actions. Новый постоянный ключ **не совпадёт** с временными debug-подписями старых APK; Android может потребовать переустановить приложение с потерей локальных данных.

## Сборка

Android SDK 35, Java 17, Gradle 8.9, Kotlin 2.0.21, Jetpack Compose Material 3.

Публикуемые APK пока являются debug-сборками; Android может не разрешить обновление без переустановки, если подпись новой APK отличается.
